# 動物病院予約管理アプリ (vet-app)

Node.js (Express) および PostgreSQL を用いた予約管理Webアプリケーションです。

## 概要
- フロントエンド：HTML / CSS / JavaScript
- バックエンド：Node.js (Express)
- データベース：PostgreSQL (pg)

## 主な機能
- **予約参照API**: 登録済みの予約一覧を取得
- **新規予約登録API**: 患者名と予約日時をデータベースに保存

## 動作方法
1. パッケージのインストール
   ```bash
   npm install
   ```
2. サーバーの起動
   ```bash
   node server.js
   ```
